# NovaVista 2004

NovaVista 2004 is an incremental roguelite disguised as a complete early-2000s desktop operating system. It combines nostalgic window management with a persistent economy, simulated social networks, minigames and procedural network raids.

## What makes it different

- A usable Windows 98/XP-inspired desktop with draggable windows, taskbar, Start menu and system applications.
- Long-term progression built around cash, followers, data, NovaCoins, implants and prestige.
- Procedural network raids with risk, trace management and permanent upgrades.
- Fully playable in Spanish and English, with instant language switching from the system tray.
- Browser-first and self-contained: the production build runs from a single HTML file.
- Automated coverage for game logic, the interface, server behavior and visual regressions.

## Project status

The current release focuses on a complete and balanced core loop: earn, invest, raid, upgrade and prestige. Pool includes an active CPU opponent, rankings use consistent ordering, and the desktop interface has been polished for clearer feedback and stronger event-driven progression.

The project is designed as both a playable game and a showcase of dependency-light JavaScript architecture, deterministic testing, interface simulation and systems-driven game design.
